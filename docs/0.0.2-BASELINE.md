# QYQ OS 0.0.2 Baseline

## Release

- Version: **0.0.2**
- Product: **QYQ OS**
- Full English name: **QiYinQiao Operating System**
- Chinese name: **七音桥 操作系统**
- Base: **Debian 13 (Trixie)**
- Architecture: **amd64 / x86-64**
- Kernel line: **Linux 6.12**
- Firmware boot: **UEFI**
- Desktop: **KDE Plasma**
- Display protocol: **Wayland**
- Display manager: **SDDM**
- Default systemd target: **graphical.target**
- Logo: **not defined in 0.0.2**

## Purpose

0.0.2 is the first graphical QYQ OS baseline.

The goal of this release is to provide a complete, conventional Linux desktop environment that can later serve as the visible execution surface for Agent demonstrations and system-level intelligent capabilities.

## Desktop Baseline

The image installs the KDE desktop stack centered on:

- `kde-standard`
- `plasma-workspace`
- `kwin-wayland`
- `sddm`
- `network-manager`
- `fonts-noto-cjk`
- `spice-vdagent`
- `qemu-guest-agent`

QYQ OS intentionally keeps the fuller `kde-standard` package set in 0.0.2 instead of aggressively minimizing the desktop image.

## Networking

Desktop networking is managed through **NetworkManager**.

`systemd-resolved` remains enabled for DNS resolution.

## Development Account

The development image contains:

```text
username: qyq
password: qyq
```

This is only for early development and testing. It is not a production account or installer design.

## Image Layout

- Raw development image size: **12 GiB**
- Partition table: **GPT**
- EFI System Partition: **512 MiB FAT32**
- Root filesystem: **ext4**
- Bootloader: **GRUB EFI**
- Removable UEFI fallback path is installed so QEMU does not require a persistent NVRAM boot entry.

## Human Validation Checklist

Before considering the graphical experience fully validated, verify manually that:

- SDDM graphical login is visible.
- The `qyq` user can log in.
- KDE Plasma loads successfully.
- The session is Wayland.
- Keyboard and mouse work.
- Networking works.
- A terminal can be opened.
- `sudo apt update` works.
